# GEYK 홈페이지 리디자인 MVP

GEYK의 실제 콘텐츠와 사진을 사용하고 APR의 정보 구조와 반응형 패턴을 재해석한 로컬 웹사이트입니다. 설치할 외부 패키지가 없는 HTML/CSS/JavaScript 프로젝트입니다.

## 실행

이 폴더에서 `npm run dev` 실행 후 http://127.0.0.1:4173 에 접속합니다. Python 3가 필요합니다. `npm run check`로 JavaScript 문법을 확인할 수 있습니다. 서버 중지는 실행한 터미널에서 Ctrl+C입니다. dist 폴더를 정적 웹 호스팅에 올릴 수 있으며 이번 작업에서는 외부 배포하지 않았습니다.

## 브라우저 분석과 적용

2026-11-17 직접 브라우저로 원본을 확인했습니다.

| 대상 | 관찰 | MVP 결정 |
|---|---|---|
| GEYK 홈 | 메뉴 중복, 큰 이미지, 소개/연혁 미리보기, 최신 모집 글 3개 | 핵심 메뉴 5개와 두 가지 탐색 진입점으로 단순화 |
| GEYK History | 2013–2020년의 긴 연도별 목록 | 실제 활동 6건을 선별해 분야·연도·키워드 검색과 상세 창 제공 |
| GEYK 25기 공고 | 2026.08.11–08.21 접수, 5개 모집 팀 안내 | 마감 상태와 일정, 모집 팀, 원문을 한 화면에 정리 |
| APR 데스크톱 | 비주얼 위 가로 내비게이션, 전체 화면 히어로와 하단 탐색, 사업 영역, 성장, 뉴스, ESG, 채용 | 히어로 → 소개/정체성 → 활동 영역 → 활동 기록 → 소식 → 모집 순서 적용 |
| APR 모바일 390px | 햄버거 메뉴, 큰 비주얼, 하단 탐색 버튼, 세로 화면 구성 | 접이식 메뉴, 한 열 카드, 터치 가능한 버튼 적용 |

APR의 고유 로고·사진·문구는 사용하지 않습니다. GEYK의 이름, 비영리 청년 기후단체 정체성, 창립연도, 활동과 공고를 유지합니다. 상단 워드마크 옆 g. 심벌은 MVP용 임시 그래픽입니다. 실제 운영 전 공식 CI로 교체할 수 있습니다.

## 우선순위와 3시간 범위

- P0: 지난 활동 탐색, 모집공고 탐색, 실제 원문 연결, 모바일 메뉴, 읽기 쉬운 대비와 키보드 조작.
- P1: 단체 소개, 활동 영역, 소식, FAQ, 실제 사진과 일관된 시각 구성.
- 후속: WordPress 전체 콘텐츠 이관, 관리자/CMS, 자동 공고 갱신, 다국어, 정식 도메인 배포.

권장 시간 배분: 원본 분석 25분 / 콘텐츠·구조 20분 / 구현 90분 / 검증·수정 35분 / 인계 10분.

## 사용자 테스트

1. 홈에서 ‘지난 활동 탐색’을 찾아 이동한다. ‘국제 연대’ 선택 → COP24 상세 → 활동 원문 확인. 성공: 활동 시기·내용과 원문을 찾는다.
2. ‘2016’ 연도로 필터링해 ‘꿀벌’ 검색 → 상세를 연다. 성공: 결과 1건, 내용과 날짜 확인.
3. 존재하지 않는 키워드 검색 → 결과 없음 → 필터 초기화. 성공: 전체 6건 복원.
4. 모바일 메뉴에서 ‘멤버 모집’ 선택 → 최신 공고 확인. 성공: 25기, 마감 여부, 접수 기간, 모집 팀, 원문을 찾는다.
5. 모집 FAQ에서 다음 모집 일정을 확인한다. 성공: 아직 확인되지 않았음을 이해한다.

실제 사용자에게는 클릭 수, 완료 시간, 성공/실패, 혼동한 문구를 기록합니다. 이번 검증은 브라우저 기능 점검이며 실제 사용자 실험은 아닙니다.

## 검증 결과

- JavaScript 문법 검사 통과.
- 1440×900 데스크톱 / 390×844 모바일 화면 점검.
- 분야 필터 2건, 연도 필터 1건, 결과 없음과 초기화 동작 확인.
- 활동 상세, 모집 상세, 모바일 메뉴 선택 후 닫힘 확인.
- 모바일 문서 폭 390px: 가로 넘침 없음.
- 브라우저 JavaScript 오류 기록 없음.
- 이미지 로컬 저장, 히어로 및 캠프 사진 표시 확인.
- qa/desktop.jpg, qa/mobile.jpg에 화면 기록.

## 콘텐츠와 한계

콘텐츠는 2026-11-17 확인한 공개 자료의 정적 스냅샷입니다. 자동 갱신하지 않습니다. 아카이브 6건과 모집공고 3건은 전체 게시물 이관이 아닙니다. 상세 본문은 원문을 요약했으며 전체 내용은 외부 원문으로 연결합니다. 실제 회원 접수와 개인정보 저장 기능은 없습니다. 최신 25기 공고는 마감 상태이므로 신청 버튼을 활성화하지 않았습니다.
